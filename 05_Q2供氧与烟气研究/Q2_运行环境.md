# Q2 实际运行环境

Python 3.14.2，NumPy 2.5.1，Pillow 12.3.0。CSV/JSON、SHA256和XLSB ZIP/BIFF12读取使用标准库。Pandas、SciPy、Matplotlib、pyxlsb、PyMuPDF在当前环境不可用。数组、表格、Pearson/滞后及 PNG 绘制分别由 NumPy、CSV 标准库和 Pillow 验证。未改正式 requirements。

从含原始资料的工作区运行：
```powershell
$env:PYTHONUTF8='1'
python '05_Q2供氧与烟气研究/代码/q2_run.py' --data-dir '题目及数据/Data' --out '05_Q2供氧与烟气研究/运行检查-新' --smoke
python '05_Q2供氧与烟气研究/代码/q2_run.py' --data-dir '题目及数据/Data' --out '05_Q2供氧与烟气研究/研究成果/新运行'
```

三个真实附件的兼容检查及十炉运行均通过。内置读取器针对哈希已锁定的十份单表工作簿，解析 RK、双精度和字符串，并交叉核对共同 EDA。使用中文路径成功生成 CSV、JSON、Markdown 和 PNG。运行清单的单位依据正式数据字典。
